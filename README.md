🔮 AstroGuide – Modern Astrology Website

AstroGuide is a modern and responsive astrology platform built to provide users with personalized horoscope insights, zodiac information, 
astrology services, and an engaging spiritual experience. The project focuses on clean UI, smooth user experience, and scalable backend architecture.


🚀 Features
✨ Beautiful modern UI/UX
🔐 User Authentication System
♈ Zodiac Sign Information
🌙 Daily / Weekly Horoscope
📅 Astrology Consultation Booking
🧙 Astrologer Profiles
💬 Contact & Inquiry System
📱 Fully Responsive Design
⚡ Fast Performance
🌐 SEO Friendly Pages
